# TRN event archive

The nine concert photographs in this folder were recovered from commit `c5cfbbd2fc6ed78fdbe8ea9800476fd1be288671`, under `public/pics/`. These are the optimized versions already used by the original site, with their existing watermarks preserved.

`hero-video.mp4` was recovered from the same commit's `public/images/hero-video.mp4`. `hero-poster.jpg` is its frame at two seconds, used before playback and when motion is reduced.

These are supplied project assets, not newly sourced stock media. The repository does not include photographer or licence metadata.
